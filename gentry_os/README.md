# THE GENTRY AI OS

## Mission
Operate The Gentry's content intelligence system with the least possible dependence on April.

The system turns real conversations, market intelligence, brand knowledge, and performance data into decisions and content.

## Primary Workflow

RAW INPUT
→ INTELLIGENCE
→ DECISION
→ CONTENT
→ APPROVAL WHEN REQUIRED
→ PUBLISH
→ MEASURE
→ LEARN

## Chief of Staff

The Chief of Staff is the orchestrator.

It decides:
- what information matters
- which specialist agent should handle it
- whether content should be created
- which Gentry content machine it belongs to
- what requires April
- what can happen without April
- what should be measured
- what the system should learn

## Specialist Agents

### 1. Miner
Extracts intelligence from:
- chair conversations
- transcripts
- voice notes
- client questions
- interviews
- internal conversations

### 2. Research
Finds:
- men's grooming problems
- search behavior
- Reddit conversations
- market trends
- competitor gaps
- cultural conversations relevant to Gentry

### 3. Strategist
Turns intelligence into content decisions.

Routes opportunities into:
- A1 / April Authority
- Gentry Client Acquisition
- Bourbon & Barbers
- Employer / Recruiting
- Intelligence Bank Only

### 4. Producer
Turns approved opportunities into:
- scripts
- talking prompts
- captions
- carousels
- short-form video concepts
- long-form concepts
- production instructions

### 5. Publisher
Distributes approved finished content.

### 6. Analyst
Measures performance and tells the system:
- MAKE MORE
- MODIFY
- STOP
- TEST

## Operating Rule

April should not operate the machine.

April's highest-value inputs are:
1. Talk
2. Serve clients
3. Tell stories
4. Answer high-value questions
5. Make decisions only when human judgment is actually required

Belen handles physical capture/editing when human production is required.

The AI OS handles the rest wherever technically possible.

## V1 Finish Line

A real recording enters the system.

The system:
1. receives it
2. transcribes it
3. extracts intelligence
4. stores useful intelligence
5. determines whether content should be created
6. selects the correct content machine
7. produces the content asset
8. identifies any human action required

V1 is not complete until this happens end-to-end with a real Gentry recording.
